This page assumes the [scaffolded project](/getting-started/installation/) with `npm run
dev` and `npm run editor` both running. Keep the browser tab where you can see it.

## What is already there

The editor opens on the template's one scene, `level`, with three actors in it. Select one
in the scene tree and the inspector shows its components — every actor has a `Transform`,
which holds position, rotation and scale, and then whatever else it was given:

- **camera** — a `Camera`. It is what the viewport looks through: its `Transform` sets
  where the view is centred and the component's `zoom` how close in it is. A scene without
  one still draws, centred on the origin at 1&times; zoom.
- **player** — a `Sprite` to draw, `KeyboardControl` to turn keys into events, `Animatable`
  to cycle the sprite's frames, and `Movement`, a component from `src/game/` rather than
  from the engine.
- **background** — a `Sprite` in `repeat` mode, tiling one texture across the field.

## Change something

Select **player** and open its `Movement` component. Set `speed` to `500` and look at the
browser tab: it has already reloaded, and the player is faster.

That loop is the whole workflow. The editor saved `data/data.json`, your entry point
imports that file, and Vite reloaded the page.

`Movement` is not built in. It is [a component in the
project](/writing-game-code/components/), and the inspector knows about its `speed` field
because the class says so — which is why your own components look no different from the
engine's here.

## Add an actor

<Steps>

1. Select **level** in the scene tree, then press the first button in the explorer's
   action bar, just above the tree — *Add New Actor*. The actor appears at the end of the
   scene, named `Actor`, with a `Transform` already on it. Rename it in the inspector's
   `Name` field.

   The button acts on whatever is selected: with an actor selected instead of the scene,
   the new one becomes its child.

2. Add a `Sprite` component to it.

3. Point the sprite at an image. Anything in `data/assets/` is selectable, and a file you
   drop in there appears without restarting the editor.

</Steps>
